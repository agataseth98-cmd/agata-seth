# Segurança

Este é um projeto pessoal de operador único; não há suporte formal nem prazo garantido.

## Como reportar

Use *Report a vulnerability* na aba **Security** do repositório (relato privado), quando disponível. Se não estiver, abra uma issue pedindo contato **sem detalhes técnicos** do problema; o autor responde por canal privado.

Não publique em issue ou PR: credenciais, chaves, nem passo a passo de falha ainda não corrigida.

## O que está no escopo

O canon (regras, scripts, hooks, workflows). Segredos nunca ficam no repositório (`CHAVES.md` é só checklist). Mudanças protegidas só entram com assinatura do autor (ver `propostas/README.md`).
